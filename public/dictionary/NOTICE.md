# Offline learning dictionary

The English–Chinese headword, phonetic, definition, frequency and inflection
data in this directory are derived from ECDICT:

- Project: https://github.com/skywind3000/ECDICT
- Copyright: Copyright (c) 2025 Linwei
- License: MIT

The data has been filtered to single-word learning entries, trimmed to a small
number of senses, and split into prefix shards for on-demand use. Dictionary
entries provide general lexical possibilities; Dedicated to Fx does not present
them as an automatic analysis of the current sentence.
